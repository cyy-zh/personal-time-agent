# 使用说明（开发候选版）

本应用尚未完成完整产品验收。尤其没有完成 ColorOS 真机、多日使用统计、视觉分类准确率与提醒可见性测试。请勿把本版本用作唯一的重要事项提醒渠道。

## 安装与首次配置

安装 APK 后，任务数据保存在手机本地。正式应用与旧 Widget Probe、Reminder Probe 使用不同包名，不会自动读取旧探针的数据。所有可选模块默认关闭，在“设置”按需开启；系统授权与应用开关是两回事。

## 任务、日程与计时

“今日”可手动添加任务；打开“编辑详情、时间与提醒”设置预计分钟数、重要程度、真实截止日期、执行时间和锁定状态。日期格式为 `yyyy-MM-dd HH:mm`，按设备当前时区解释。锁定活动用于表示课程等固定安排。

“生成一周排程提案”会提出安排；在“提案”查看实际待执行内容并确认。任务完成、AI 修改及排程建议经确认后生效，操作记录可撤销；有后续修改或新冲突时撤销会被拒绝。

“账本”支持按类别开始、暂停与结束计时，运行状态保存在本地，应用退出后可继续处理。暂停会保存本段实际时间。计划时间不自动算成实际时间。“统计”汇总实际记录并处理重叠区间。

## AI 对话与模型 API

在“设置”填写兼容 Chat Completions 协议的完整 HTTPS 接口地址、模型名称、服务商和 API Key，并选择允许发送的数据范围。地址应是实际请求端点（通常以 `/chat/completions` 结尾），并非只填网站首页。Key 加密保存在设备，不随备份导出。

开启 AI 任务规划后，“对话”中未被本地规则处理的指令可以点击“调用 AI”。网络失败时指令保留；模型只生成候选变更，必须在提案页确认。任务、目标、账本与通知有独立的数据发送授权；截图不发送。已识别的时间统计问题直接读取本地记录回答，缺少记录不代表实际投入为零。

## 目标、习惯与复盘

在设置中开启对应模块，再进入目标或习惯页面。新目标、习惯及阶段任务会进入提案页。习惯周安排由当前日程和空档生成，避免重复创建同一来源实例。完成记录用于本地统计。

“历史趋势与复盘”展示有证据的本地记录、样本量及有限的偏好推断。主动 AI 复盘需单独开启，并设置频率与调用预算；系统可能延迟执行。模型请求仅使用当前授权范围。记录较多的时段不等于已证明效率最高。

## 提醒与 Widget

开启普通提醒模块，在“权限与提醒”允许系统通知，按需要开启精确闹钟权限。无精确闹钟权限会使用可能延迟的调度方式。任务的提醒时间由编辑或排程设置。界面中的“submitted”只表示已向系统提交，不能证明用户已看到。

通过 ColorOS 桌面卡片/小组件列表添加“个人时间 Agent”。组件提供任务展示及快捷操作。系统强制停止应用可能影响后续后台工作，重新打开后应核对提醒状态。

## 可选采集

- **手机使用**：开启模块并授予使用情况访问权，读取所选周期；后台采集受系统调度约束。App 时长不会直接归类为微信视频号等内部活动。
- **通知收件箱**：系统授予通知使用权后，还需开启采集并选择微信/QQ。正文保存有单独开关，默认关闭。已有正文可手动加入待办候选输入，发送 AI 仍检查通知授权范围。没有回调不能直接证明应用未发布通知。
- **活动与模型**：授予无障碍访问权、选择允许的应用，独立开启活动识别、模型与自动截图。仅使用官方接口，不操作其他应用。安全窗口或缺少权限时降级。
- **视觉模型**：需要兼容图像输入的 LiteRT-LM 模型与可信 SHA-256；下载需要遵守模型自己的许可证。安装应用不自动下载模型。当前候选模型尚未经本机实测，输出得分未校准，不等于已达到 90% 准确率。

## 备份与恢复

在“备份”输入至少 12 字符口令，导出加密文件。口令不能找回。备份包含主要数据库记录，不含 API Key、采集授权、模型文件、截图或通知来源的原始输入。已由用户确认形成的任务属于任务数据，会正常备份。

恢复先校验备份并展示记录数量，需明确确认替换当前数据库。当前数据库会先另存为本机加密恢复副本。恢复后所有模块关闭，待审核提案失效；应重新检查设置、授权和未来提醒。手机数据恢复尚需实际设备验收。

## 当前限制

完整的七天/24小时观测、20次提醒测试、各类视觉人工标注样本测试尚未进行。第三方 API 的不同实现、模型许可下载入口、厂商后台管理及应用界面变化均需要真实验证。完整需求和逐项验收状态见 `product-requirements.md` 与 `acceptance-matrix.md`，不能将构建成功理解为完整产品通过验收。
